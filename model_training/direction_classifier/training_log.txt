======================================================================
ViT direction + pose classifier — training run for best_model_v7.pt
======================================================================
Trained on a Windows / NVIDIA RTX 2060 SUPER (8 GB) box, CUDA 12.8,
PyTorch 2.11, mixed precision.

CONFIG
----------------------------------------------------------------------
Backbone            : google/vit-base-patch16-224-in21k
Heads               : 9-class direction + 2-class pose (shared backbone)
Batch size          : 64
Max epochs          : 60   (early-stop patience 10)
Learning rate       : 2e-5
Pose class weights  : [1.0, 2.2]     (Regular : Upside-down)
Augmentation        : ColorJitter + GaussianBlur(p=0.10) + horizontal flip
                      (train split only; direction label mirrored, pose kept;
                      NO vertical flip — see README "What we tried")

DATASET
----------------------------------------------------------------------
Train 4144 / Val 893 / Test 894
Temporal-chunk split (chunk = frame_id // 150) so consecutive video frames
never straddle train/val/test. Pose labels: ~3862 regular / ~796 upside-down
across the whole set (upside-down mined from real runs, no synthetic flips).

NOTES
----------------------------------------------------------------------
- Test val/test crops come from the same source videos as training (no fully
  held-out video), so these numbers track training progress but are not a
  generalisation guarantee. Real evaluation is a manually reviewed inference

  runs; phase 3 mitigates this with config.UPSIDE_DOWN_CONF_THRESHOLD.
